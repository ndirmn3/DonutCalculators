Gambling Calculator

Paper Game and Arrow Game strategy calculators.

Paper Game

Host has 1–9 and Viewer has 1–9. Host wins when Host ≥ Viewer. Viewer wins when Viewer > Host and receives 2× their payment. Viewer win chance: 44.44%.

Enter a minimum and maximum entry price.
Losses increase the next payment using a slowing logarithmic progression. Wins decrease the next payment by ½. The payment stays between your min and max.
Enter valid min/max values to see a suggested payment.

Simulation

Each simulation starts at the minimum and continues using the same payment logic until the stop suggestion is reached.
Enter min/max prices and a quantity to simulate.

Arrow Game Calculator

Viewer pays the host an amount between the minimum and maximum. If the arrow lands on Lose, the host keeps the payment. If it lands on Win, the host pays the viewer 2× the payment.

Set the grid and mark cells as Win or Lose.
